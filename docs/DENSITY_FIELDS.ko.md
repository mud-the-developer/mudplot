# 짝지은 밀도·경험분포 필드

[English](DENSITY_FIELDS.md)

관측값, 가중치, 옵션, 행 식별자를 그대로 저장하는 워크플로다. 밀도를 빈도
높이에 맞춰 늘리거나 가중치를 표본 복제로 해석하지 않으며, 뷰포트가 바뀌어도
다시 적합하지 않는다. 검증 상태는 [동결된 v2 목록](V2_SCOPE.ko.md)을 따른다.
이 워크플로만으로 공통 축·시맨틱·레이아웃·릴리스 행까지 완료되는 것은 아니다.

## 짝지은 히스토그램과 전체 적합 KDE

```python
import mudplot as mp

d = {
    "x": [-2., -1., 0., .5, 1., 2., 3., 1.5],
    "y": [-1., 1., -.5, 1.5, .25, 2., -.5, -1.],
    "w": [1, 2, 4, 1, 3, 2, 1, 2],
    "site": ["left"] * 4 + ["right"] * 4,
}
p = mp.plot(d).hist2d(
    "x", "y", bins=mp.BivariateBinsSpec(x=[-3, 0, 1, 4], y=[-2, 0, 3]),
    stat="density", weights="w", colorbar=True,
    kde=mp.KDE2DSpec(weights="w", levels=[.5, .8], gridsize=32),
)
p.save("paired-density.svg")
```

셀 질량을 `C`, 원래 좌표의 면적을 `A`, 비교 풀의 빈 내부 질량을 `T`라 하자.

| 통계 리터럴 | 셀 값 |
| --- | --- |
| `count` | `C` |
| `frequency` | `C/A` |
| `probability`, `proportion` | `C/T` |
| `percent` | `100*C/T` |
| `density` | `C/(T*A)` |

두 좌표가 모두 범위 안에 있어야 한다. 각 빈은 왼쪽을 포함하고 오른쪽을
제외하되, 마지막 오른쪽 경계는 포함한다. 범위 밖 행도 원본에는 남는다.
필수 값 결측과 0 가중치는 적합·집계 전에 짝지은 행으로 제외한다. 음수·비유한
가중치는 거부한다. 빈 내부 질량이 없는 정규화 통계를 임의의 0 확률로 바꾸지
않는다.

`common_norm=True`는 비교 질량을 풀링하고, `False`는 유효 hue 풀을 쓴다.
size/style 튜플마다 따로 정규화하지 않는다. 빈 규칙은 선택 관측값을 쓰며
가중치 크기를 복제 횟수로 쓰지 않는다. `BivariateBinsSpec`은 논리 x/y의 빈
선택을 명시한다. 기존의 모호한 평면 리스트를 새 경계 의미로 바꾸지 않는다.
네이티브 셀은 불균등한 실제 경계와 `H.T` 방향을 사용한다.

KDE 오버레이는 **빈 범위 제외 전의 동일한 짝지은 코호트**를 쓴다. 따라서
빈 밖 관측값도 적합에 남는다. 가중치는 부모 열을 상속하거나 일치해야 하며,
`common_norm`도 같아야 한다. 자체 밀도/CDF 레벨을 빈도 높이로 재조정하지
않는다. 통계 색상 막대는 실제 필드 mappable의 원시 값과 norm을 유지한다.
축이 아닌 별도 보정 표시에서 정확한 원시 레이블을 쓰므로 양의 subnormal 값도
표시 범위를 임의로 늘려 왜곡하지 않는다.
여러 통계 막대는 소유 축의 한 네이티브 영역을 공유하되 원시 norm·눈금·인용은
각각 유지한다. 생성된 단위 설명만 줄바꿈하며 작성한 라벨·수학 토큰·정확한 원시
눈금 문자열은 줄이지 않는다. 최종 백엔드의 장식 경계가 지정 캔버스에 들어가지
않으면 명시적으로 렌더를 거부한다.
그리드에 쌓인 막대의 너비는 측정한 공유 영역에 한 번만 예약한다. 보이는
모든 막대의 네이티브 경계는 최종 검증과 여백을 자르는 내보내기에 반영된다.
제약 그리드의 단일 막대는 생성된 단위 라벨의 실제 높이가 캔버스를 넘을 때만
기존 공백에서 줄을 바꾼다. 단위 수식과 원시 보정은 그대로이며 같은 최종
경계 검사를 거친다.

## 이름 있는 커널, 누적 법칙과 구성비

`gaussian`과 `epanechnikov_product`는 동일한 공분산 H 의미를 쓴다. 압축 지지
커널은 분산 1 Epanechnikov이며, 2차원에서는 Cholesky 백색화 뒤의 곱이다.
**방사형·회전 불변 커널이 아니다.** 대역폭 행렬은
`H = Σ_unbiased * (factor * bw_adjust)**2`이며 `factor`는 Scott/Silverman
또는 API의 유한 숫자 계수다. 1차원은 `h = sqrt(variance) * factor * bw_adjust`다.
물리 행 Kish 크기는 동점 집계 전에 구한다. 특이 필드는 요청한 경고 정책에 따라
제외하며, jitter나 가짜 대역폭을 만들지 않는다.

```python
mp.plot(d).kde(
    "x", group="site", weights="w", kernel="epanechnikov_product",
    multiple="fill", common_grid=True, cumulative=True, fill=True,
).save("cdf-composition.pdf")

mp.plot(d).kde2d(
    "x", "y", weights="w", cumulative=True, level_kind="cdf",
    levels=[.2, .5, .8], gridsize=32, colorbar=True,
).save("true-joint-cdf.svg")
```

1차원 `layer`, `stack`, `fill`은 필요한 경우 저장된 공통 그리드를 쓴다.
숨겨진 보간은 없다. Stack은 실제 기여를 더하고, fill은 그 합으로 나눈다.
압축 커널의 실제 0 영역은 간격으로 남기며 균등 지분이나 가짜 0을 만들지
않는다. 누적 stack/fill은 기여·구성비 표시이지 **모집단 CDF가 아니다.**
2차원 stack/fill은 정의된 높이 축이 없으므로 거부한다.

결합 KDE CDF는 두 좌표의 음의 무한대부터 원래 적합 법칙을 적분한다. 유한
그리드 질량으로 다시 기준을 잡지 않는다. 고정 절대 수치 오차 예산은 `1e-6`이다.
그룹의 `common_norm` 진폭은 명시적인 기여로 남으며 숨겨진 필드별 재정규화가
없다. Cut/clip은 질의·뷰를 고를 뿐 적합 행을 줄이지 않는다.
Gaussian 직사각형은 부호 있는 Plackett 적분, 바깥 방향 미분·정확한 중점의
포함구간과 현재 leaf의 정확한 dyadic 합을 쓴다. 동일 결과 재사용은 한 필드에만
속하며 native 출력 전에 끝난다. 임의 상대 정밀도 보장이 아닌 절대 오차 계약이므로
해결되지 않은 원천·수치 불확실성은 명시적 오류다.

논리 입력별 `fit_scales=["data", "axis"]`가 적합 좌표를 고른다. 실제 로그 축은
표시 밑과 관계없이 log10을 쓴다. `density_space="data"`는 원시 밀도 Jacobian을
포함하고, `"fit"`은 작업 좌표 밀도다. CDF에는 Jacobian을 곱하지 않는다.
Symlog/asinh/logit 또는 절대 달력의 로그 적합을 원시 도형 지원에서 추론하지
않는다. 네이티브·로그·날짜 좌표가 표현되지 않으면 epsilon 이동이 아니라
명시적 정밀도 오류로 처리한다.

## 조건부 그리드가 아닌 명시적 전체 모델 HDR

```python
mp.plot(d).kde2d(
    "x", "y", weights="w", levels=[.8, .95], gridsize=17,
    hdr=mp.HDRSpec(scope="full", tolerance=.01),
    fill=True, line_width=0, colorbar=True,
).save("full-model-hdr.pdf")
```

`HDRSpec`이 없으면 기존의 유한 그리드 조건부 등고선 정의를 유지한다. 전체
모드는 원래 적합 법칙에 대해 알려지지 않은 엄격한 순서의 밀도 절단값을
보정한다. 네이티브 집합은 내부가 보장된 적응 셀들의 합집합이다. 매끄러운
등고선인 것처럼 표시하지 않는다. 중첩 요청도 모든 레벨과 서로 겹치지 않는
최초 밴드를 유지한다. 로그 적합 뒤 원시 밀도 HDR은 포함 판정에 Jacobian을
쓰지만, 확률은 여전히 원래 적합 법칙에서 적분한다.

요청 절대 조건부 허용오차는 양수이며 최대 `.05`다. 지지 생략, 적분·분류,
원본·변환, 네이티브 기하, 실제 클리핑의 오차를 분리해 기록한다. 명시된
IEEE·계산 모델 가정하에서 목표 질량과 HDR 영역 대칭차 오차가 모두 풀려야
한다. 실제 보이는 클리핑 확률을 **목표 p라고 부르지 않는다.** 물리적 외곽선은
장식이며 추가 확률 질량이 아니다. 순서·허용오차·좌표·자원이 풀리지 않으면
전체 효과를 거부한다. 레벨 생략, 허용오차 대체, 조건부 fallback은 없다.

같은 figure의 배치 계산과 내보내기에서는 네이티브 경로와 축 정책이 같고,
실제 백엔드의 아핀 변환·직렬화 오차가 인증 범위 안에 있을 때만 적합 기하
증명을 재사용한다. 각 그리기에서 자체 클리핑과 가시 확률을 확인한다.
경로나 축 정책 또는 오차 범위가 달라지면 다시 증명한다. 지원하지 않는
위상이나 증명되지 않은 오차 범위는 그리기를 거부한다. 재사용은 자원 원장을
초기화하거나 한도를 늘리지 않는다.

## 명시적인 짝지은 경험적 CDF

```python
mp.plot(d).ecdf2d(
    "x", "y", bounds=[[-3, 4], [-2, 3]], weights="w",
    stat="percent", complementary=True, query_x=[0, 1], query_y=[0, 1],
    colorbar=True,
).save("joint-empirical.svg")
```

하위 직교 영역은 `X <= qx AND Y <= qy`다. 엄격한 여집합은
`X > qx OR Y > qy`이며 **AND 생존함수가 아니다.** 통계 리터럴은
`proportion`, `percent`, `count`다. ECDF에 `probability` 별칭을 추가하지 않는다.
경계·질의는 분모 관측값을 제거하지 않는다. 내부 원본 매듭, 동점, 질의를
모두 유지하고 오른쪽 연속 셀을 그리며 평활화하지 않는다. 원본·질량을 동점
집계와 최종 float 반올림 전에 정규 표현으로 유지한다. Percent 단위도 최종
반올림 전에 결합하여 표현 가능한 작은 점프를 지우지 않는다.

## 좌표·역할·라이브 뷰·한계

- `orient="h"`는 표시 역할만 바꾼다. 실제 primary/y2 대상과 입력별 선언 시계가
  변환을 정한다. 확률·밀도는 날짜가 아니다.
- 시간 bin/clip/bounds/query는 기존 규칙대로 ISO 문자열 또는 1970년 이후의
  정규 UTC day 좌표다. 관측값의 `s/ms/us/ns/day` 입력 단위로 재해석하지 않는다.
  숫자 관측값에는 명시 단위와 origin이 필요하다. 밀도 면적은 각 시계 차원의
  정규 day 폭을 사용한다.
- SIZE는 실제 주 선 또는 셀·등고선 외곽선의 포인트 두께다. 면적·질량·빈 너비·
  가중치가 아니다. STYLE은 실제 dash를 쓰고, 실제 관측 매듭의 마커는 1차원
  ECDF에만 있다. HUE의 원시 필드 색조와 통계 mappable은 구분한다. 소유된 역할의
  스칼라 충돌은 후보 수락 전에 거부한다.
- 로컬 `ReplaceLayer`는 로컬 편집이다. `SetFacetTemplate`만 고정 라이브 셀을
  명시적으로 교체하고 로컬 재정의를 덮어쓴다. 저장본을 열면 그 뷰를 보존한다.
  렌더·미리보기는 저장된 관측·옵션에서 재계산하며 템플릿 전체 교체를 몰래
  실행하지 않는다. N13 ID와 선택자는 유지한다.
- NEW 짝·필드 요청의 한계는 레이어당 선택된 양의 완전한 물리 행 10,000개,
  원시 튜플 필드 256개, 범주 수준 64개다. 수치 원시 값의 고유 개수를 임의로
  64개로 줄이지 않는다. 히스토그램은 축당 512빈, 결합 ECDF는 축당 512경계,
  KDE2D는 축당 256노드와 16레벨이다.
- 하나의 NEW figure 원장이 합성 작업 20억 단위, 전체 작업·보유 기하·네이티브
  계획·artist 256 MiB, 동시에 살아 있는 수치 pair 스칼라 100만 개, 닫힘을 포함한
  네이티브 경로 정점 200만 개를 사전 검사한다. 전체 HDR은 현재 레벨의 활성 셀
  65,536개와 최초 시도 외 절단값 갱신 48회까지다. 필드·레벨마다 초기화하지 않는다.
  코호트·그룹 구성, 경험 경계·정렬 계획과 네이티브 검사는 할당 전에 수락하며
  임시 구성 저장소는 네이티브 출력 전에 끝난다. 원본 라벨·관측값은 복사하지 않고
  참조로 유지한다.
- 이 값들은 유한 수락 경계이지 **FLOPs·RSS·SLA가 아니다.** 백엔드 RGBA 버퍼는
  기존 40M 픽셀 규칙하에서 이 예산 밖에 둔다. 기존에 수락되던 일반·가중·누적
  1차원 경로와 동일 Gaussian의 순수 기하 보완에 새 경계를 소급하지 않는다.
  D01/C07 원장은 별개다. CLI·편집기 실패는 일부 결과를 공개하지 않고 수락된
  전체 출력·원본·이력을 유지한다.
