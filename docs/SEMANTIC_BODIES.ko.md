# 히스토그램과 도수 막대의 공유 시각 매핑

[English](SEMANTIC_BODIES.md) · [실행 예제](../examples/semantic_bodies.py)

명시적 통계 옵션을 사용하는 `hist(..., stat="density", semantics=...)` 또는 `countplot(..., semantics=...)`에 `SemanticSpec`을 지정합니다. 색은 채워진 면 또는 비어 있는 히스토그램의 선에 적용됩니다. 크기는 외곽선의 포인트 단위 두께이며, 면적·빈 너비·질량이 아닙니다. 스타일은 선의 대시이며 별도 마커를 만들지 않습니다. 이미 매핑한 속성을 스칼라 옵션으로 덮어쓸 수 없습니다. 기존 `group`과 크기·스타일 매핑은 함께 사용할 수 있지만 색 매핑까지 동시에 지정할 수 없습니다.

같은 색으로 표시되는 값도 원래 값이 다르면 별도로 집계합니다. 히스토그램 밀도 분모에는 이동 전 빈 너비와 범위 내 가중 질량을 사용합니다. `common_norm=False`이면 색 그룹의 두께·스타일 조합들이 동일한 질량 분모를 사용합니다. 도수 정규화의 `all`, `category`, `group`은 각각 전체·범주·유효 색 그룹을 기준으로 합니다. `scale_id`는 표시 범위만 공유하며 통계 분모에는 영향을 주지 않습니다. 숫자 색 컬러바는 원본 색 열을 표시하며 이변량 통계 컬러바와 구분합니다. 옵션을 생략하면 이전 동작을 유지합니다.
